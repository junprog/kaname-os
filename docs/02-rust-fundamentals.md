# 第2章 OS開発に必要なRust

## 学習目標
所有権、借用、参照、ポインタ、`unsafe` の違いを説明できる。

## 所有権
Rustでは値の所有者が原則1つ。`String`などのmoveでは通常、ヒープ上の文字列データそのものは複製されず、所有権が移る。`clone()`は内容を複製する。

## スタックとヒープ
`String`は概念上、ポインタ・長さ・容量を保持し、文字列データをヒープに格納する。実際の配置はコンパイラ最適化の影響を受ける。

## 参照とポインタ
`&T`は共有参照、`&mut T`は排他的な可変参照。raw pointer（`*const T` / `*mut T`）は参照とは異なり、安全性をコンパイラが同様には保証しない。ポインタの参照外し等には`unsafe`が必要。
