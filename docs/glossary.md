# 用語集

| 用語 | 意味 |
|---|---|
| CPU | 命令を実行するプロセッサ |
| RAM | 実行中のコードやデータを保持する主記憶 |
| ISA | CPUが理解する命令セットの仕様 |
| MMU | 仮想アドレスの変換等を行うハードウェア |
| UEFI | PC起動時のファームウェア規格 |
| ブートローダー | カーネルをロードして制御を渡すプログラム |
| カーネル | OSの中核部分 |
| Cargo | Rustのビルド・パッケージ管理ツール |
| リンカー | コード・データを結合し配置・参照を解決するツール |
| ELF | 実行コードとロード情報等を格納する形式 |
| PIE | 配置位置に依存しない実行形式 |
| エントリーポイント | 実行開始位置 |
| セグメント | ローダーが扱うメモリロード単位など |
| セクション | ELF内でコードやデータを分類する単位 |
