# 第1章 コンピュータの仕組み

## 学習目標
CPU・RAM・ストレージの役割、機械語、メモリアドレス、仮想アドレスの意味を説明できる。

## CPUとメモリ
CPUは命令を実行し、RAMは実行中の命令やデータを保持する。SSDは電源を切っても内容を保持する記憶装置。CPUは命令を読み、解釈し、実行する（Fetch → Decode → Execute）。これは概念モデルであり、現代CPU内部ではパイプライン等によって処理が重なり得る。

## レジスタ
RAXなどは汎用レジスタ。RSPはスタックポインタ、RIPは命令ポインタ、RFLAGSは状態フラグを保持する。

## アドレス
アドレスはメモリ中の位置を示す番号。`0x` は16進数を表す。通常のユーザープログラムでRustのポインタとして観察できるのは仮想アドレスであり、物理RAMの番地そのものではない。MMUとページテーブルが変換を担う。
