### 1. 実装形式・技術要件
- **単一のHTMLファイル**（HTML / CSS / Vanilla JavaScript / HTML5 Canvas）として完結させ、外部ビルドなしでブラウザでそのまま動作するようにしてください。
- UIのラベル、タイトル、ステータス表示、単位、ツールチップは**すべて自然な日本語**で表記してください。
- ダークモード基調のクリーンで工学的なダッシュボードデザインにしてください。

### 2. 画面構成とデータフロー（上から下へアニメーションで接続）
Stage 2 → Stage 3 → Stage 4 へとデータが流れる様子を、パイプラインの接続線と流れるパルスアニメーションで表現してください。

#### 【上部パネル】Stage 2: 相関演算 & サブピクセル補間
- **左グラフ（1Dバンドパス波形比較）:**
  - 基準信号 $f_A[x]$ と、シフト量に応じた比較信号 $f_B[x + d]$ を重ねて描画。
- **右グラフ（SAD相関カーブ & 等角直線フィッティング）:**
  - 探索範囲 $d \in [-16, +16]$ の SAD（差分絶対値和）カーブを描画。
  - 整数シフトの最小点 $d_0$ とその前後3点 $(d_0-1, y_{-1}), (d_0, y_0), (d_0+1, y_{+1})$ を強調表示。
  - V字の左右の傾きから交点を求める**等角直線フィッティング**の補助線を描画し、サブピクセル視差 $\Delta x$ の頂点を明示。
  - マウスホバーで各シフト量 $d$ の SAD 値をツールチップ表示。

#### 【中部パネル】Stage 3: 信頼度評価（コンフィデンスゲート）
Stage 2 の結果から以下3つの指標を計算し、ゲージと合否バッジで表示してください。
1. **コントラスト評価値**（信号勾配の絶対値和）
2. **相関谷の急峻さ（Sharpness）**（最小点と隣接点の落差をコントラストで正規化した値）
3. **繰り返しパターン判定（第1極小値 vs 第2極小値比率）**
- **ゲート挙動:**
  - 3条件すべてクリアした場合：「**測距OK（有効）**」として緑色に点灯し、Stage 4 へデータフローのパルスを通過させる。
  - いずれかが閾値未満の場合：「**測距NG（ローコントラスト / 偽合焦リスク）**」として赤色に点灯し、Stage 4 への出力をブロック（レンズ駆動を停止）する。

#### 【下部パネル】Stage 4: 光学デフォーカス & レンズ駆動制御
- **光学断面アニメーション（Canvas描画）:**
  - 左にフォーカスレンズ群、右にイメージセンサー面を配置。
  - レンズの上側瞳（A像光束）と下側瞳（B像光束）から出た2本の光線がレンズを通過し、センサー面の前方（前ピン）、センサー面上（合焦）、または後方（後ピン）で交差する様子をリアルタイム描画。
  - センサー面から交点までの距離を **デフォーカス量 $\Delta L\ [\text{mm}]$** として矢印・寸法線で表示。
- **アクチュエータ駆動インジケータ:**
  - 算出された **レンズ駆動方向**（`繰り出し (FAR → NEAR)` / `繰り込み (NEAR → FAR)` / `合焦停止`）と **レンズ駆動量 $\Delta z_{\text{lens}}\ [\text{mm}]$** を数値とアニメーション矢印で表示。

### 3. 操作コントロール（UIパネル）
ユーザーがリアルタイムにパラメータを変更できるコントロールを配置してください。
1. **初期視差 / デフォーカス量スライダー:** `-12.0 px` 〜 `+12.0 px`（初期値: `+4.35 px`）
2. **被写体パターン切替（ラジオボタンまたはタブ）:**
   - `通常エッジ`（明瞭なステップエッジ＋高周波テクスチャ）
   - `低コントラスト`（信号振幅が極小でノイズに埋もれるケース → Stage 3 でNGになる）
   - `繰り返しパターン`（周期的な格子縞でSADに複数の谷ができるケース → Stage 3 でNGになる）
3. **実効F値 / 基線長係数 $K$ スライダー:** `1.4` 〜 `8.0`（初期値: `2.8`）
4. **フォーカス敏感度 $S$ スライダー:** `0.5` 〜 `3.0`（初期値: `1.45`）
5. **アクションボタン:**
   - **「1ステップ駆動（AF追い込み）」ボタン:** 現在の駆動指令 $\Delta z_{\text{lens}}$ に基づいてレンズ位置を滑らかにアニメーション移動させ、クローズドループ制御（ゲイン $\alpha = 0.85$）で視差とデフォーカス量がゼロへ収束していく挙動を再現する。
   - **「リセット」ボタン:** 初期状態に戻す。

### 4. 厳守すべきアルゴリズム・数式仕様
シミュレーション内部の計算は以下の数式に忠実に実装してください。
- **画素ピッチ:** $p = 0.0044\ [\text{mm/px}]$
- **バンドパスフィルタ:** 1D信号に対してカーネル `[-1, -2, 0, 2, 1]` を畳み込み。
- **SAD相関:** $E(d) = \sum |f_A[x] - f_B[x + d]|$
- **等角直線フィッティング（サブピクセル補正 $\delta_{\text{sub}}$）:**
  - $y_{-1} < y_{+1}$ のとき: $\delta_{\text{sub}} = \dfrac{y_{-1} - y_{+1}}{2(y_{+1} - y_0)}$
  - $y_{-1} \ge y_{+1}$ のとき: $\delta_{\text{sub}} = \dfrac{y_{-1} - y_{+1}}{2(y_{-1} - y_0)}$
  - 推定視差: $\Delta x = d_0 + \delta_{\text{sub}}$
- **デフォーカス量:** $\Delta L = K \cdot (\Delta x \cdot p)$
- **レンズ駆動量:** $\Delta z_{\text{lens}} = \alpha \cdot \dfrac{\Delta L}{S}$ （$\alpha = 0.85$）

すべての計算はスライダー操作やステップ駆動ボタンに連動して即座に再計算・再描画されるようにしてください。
